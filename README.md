# AoA3 1.16.5 Fixes

A add-on bug-fixing mod  for [Advent of Ascension](https://github.com/Tslat/Advent-Of-Ascension) **1.16.5-3.6.11**.

## What it fixes

- **Skills wiped on the host in LAN worlds.** When another player disconnects from a  
  singleplayer/LAN world, the host's skills, resources and ability keybinds are cleared, and the Advent GUI wrongly reports *"Skills have been disabled by the server owner"*.
- **Entity attack range too long.** In Survival the range distance is about ~4.5 blocks instead of vanilla's 3.
